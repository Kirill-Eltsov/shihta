**Вопрос G1 (по плану):** есть ли содержательная задача оптимизации?

1. Есть множественные допустимые рецептуры на марку (кандидаты I2-K-05; почти все позиции с >1 кандидатом).

4. Пакет baseline доступен в git (`docs/iteration2/I2-K-09_baseline_pack.md`).
