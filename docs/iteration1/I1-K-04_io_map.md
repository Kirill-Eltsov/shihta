# I1-K-04 — Карта входов / расчёта / выходов доступной программы

Источник: `docs/MILP_Solvers.ipynb` (наработки Данила)  
Исполнитель: Кирилл Ельцов

## 1. Цепочка (доступные части)

```
XLS (Шихта, Заказы, Линии дозирования)
        ↓  pd.read_excel (лист «март 2022»)
recipes / orders / supply / quality (q)
        ↓
методы: MILP_HiGHS, LP_Relax, Greedy_*, SimAnneal [, ILP_CBC]
        ↓
назначения рецептур + метрики + CSV/графики результатов
```

## 2. Загрузка исходных файлов

| Вход (ожидание notebook) | Локальный файл у нас | Статус проверки |
|--------------------------|----------------------|-----------------|
| `Шихта.xls` | `data/raw/Шихта.xls` | читается |
| `Заказы.xls` | `data/raw/Заказы.xls` | читается |
| `Линии_дозирования.xls` | `data/raw/Линии дозирования.xls` | читается; **имя с пробелом**, notebook ждёт `_` и Colab upload |

Дополнительно (ячейки q / полный эксперимент): `Прессовка.xls`, `Проценты.xls` — есть в `data/raw/`, но основной мартовский сценарий строится на трёх книгах выше.

Непроверенные участки реализации (без полного прогона Colab):

- `google.colab.files.upload` — только Colab;
- закомментированный / отдельный путь `ILP_CBC` через pulp;
- полный эксперимент 5×q × 8 методов (ячейка 15) — требует pulp и подготовленных CSV.

## 3. Откуда берутся сущности модели

| Сущность | Источник в notebook | Поля / идея |
|----------|---------------------|-------------|
| Потребность (заказы) | `Заказы.xls` | спрос по заказам / маркам массы |
| Кандидаты рецептур | `Шихта.xls` | `Марка массы, код` + `Номер шихты` + нормы компонентов |
| Расход / запасы (supply) | `Линии дозирования.xls` | факт расхода × `SUPPLY_BUFFER` (параметр 1.30) |
| Оценка q | в базовом сценарии — качество рецепта из подготовки данных notebook; варианты q1…q5 в отдельных ячейках (в т.ч. выход прессовки) | без полной истории прессовки q2 может быть пустым (см. наш prep) |

## 4. Где выполняется расчёт

| Метод | Ячейка (по порядку notebook) | Движок |
|-------|------------------------------|--------|
| MILP_HiGHS | ~6 | `scipy.optimize.milp` |
| LP_Relax | ~7 | LP + жадное округление |
| ILP_CBC | ~8 | pulp + CBC (в базовом блоке закомментирован) |
| Greedy_Quality | ~9 | эвристика |
| Greedy_Demand | ~10 | эвристика |
| SimAnneal | ~11 | имитация отжига |
| Сводка/графики | ~12 | matplotlib, фиксированные TIMES |
| Варианты q | ~14–15 | после `00_data_prep.py` / полный прогон |

## 5. Куда пишутся результаты

- В памяти: назначения `asgn`, метрики статуса/цели/времени.
- На диск / Colab download: CSV вроде `ilp_cbc_results.csv` и аналоги по методам (пути `/content/...` в Colab).
- Графики сравнения методов (ячейка визуализации).

Локально у нас воспроизведён **только этап чтения входов** (см. I1-K-03). Полный solve и сохранение результатов notebook **не заявлены**.
