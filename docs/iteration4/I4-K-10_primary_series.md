# I4-K-10 — Первичная сравнительная серия

Исполнитель: Кирилл Ельцов  
Задача Битрикс №10535  
Протокол: I4-A-09 / набор `I4_reference_v1`

## Что сделано

Запущена первая основная сравнительная серия методов `resource_milp` и `greedy_quality` на согласованных учебных экземплярах (`base`, `deficit`, `changed_q`).

```bash
python scripts/iteration4/run_primary_series.py
```

## Артефакты

| Файл | Содержание |
|------|------------|
| `data/processed/i4/primary_series/series_config.json` | конфигурация серии, окружение, hash входов, commit |
| `data/processed/i4/primary_series/series_journal.json` | полный журнал всех повторов (status, validation, timings) |
| `data/processed/i4/primary_series/results_table.md` | таблица результатов |
| `data/processed/i4/primary_series/results_table.json` | машиночитаемая таблица |

Для каждого запуска сохранены: конфигурация, входы (hash), стадии времени, ошибки/timeout (не отбрасываются).

## Граница

Серия — на учебном наборе протокола. Производственный масштаб и доказательство ускорения на больших задачах **не заявляются**.  
Независимая перепроверка планов и целей — у Алексея (I4-A-10).
