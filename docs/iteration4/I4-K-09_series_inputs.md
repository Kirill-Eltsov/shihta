| Блокер | Исправление |

| Сквозной лимит 120 с | Внешний hard-timeout на **каждый** повтор обоих методов (`ProcessPoolExecutor` + `future.result(timeout=budget)`). MILP получает остаток бюджета в `time_limit`. |

| Однопоточный режим | `OMP/OPENBLAS/MKL_NUM_THREADS=1` + диагностика CPU/ОС/load в журнале. |
