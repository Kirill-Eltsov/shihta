# I3-A-03. Итоговый протокол ML

**Обучающий эксперимент для исследовательского вывода заблокирован.** Протокол подготовлен; полезность или бесполезность ML пока не установлена.

Определение кандидата метки и список разрешённых признаков: I3-A-01_target_features.md. Разбиение и исключение будущей информации: I3-A-02_time_split.md. Нормированный q2 не заменяет подтверждённую событийную метку.

Отбор: проверенные ключи происхождения и партии, корректные единицы, положительный знаменатель, конечные значения, исключённые повторы. Причины исключения сохраняются отдельно. Строки с неизвестными временем или меткой не заполняются выдуманными значениями.

Контроли: постоянная 1, глобальное среднее обучения, иерархическое среднее рецепта/марки/обучения. Лучший контроль выбирается по апрелю; сравниваемая модель проверяется на тех же строках. Метрики и группировки заданы до финального теста. При малых группах публикуется число наблюдений, а не обещание надёжности.

Необходимые входы для снятия блокировки: подтверждённые good/bad и единицы, стадия, точное время события и принятия решения, партия, версия рецептуры, происхождение доступных заранее признаков. Охват всех 23 марок не заявляется. Майский финальный тест не проводился.
