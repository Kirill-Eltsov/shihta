# I3-A-09. Матрица выбора метода

| Условие | Доказательство | Следствие |
|---|---|---|
| Технический выбор рецептур | Во второй итерации 25/25 заказов имеют альтернативы | Технологическое разрешение ещё требуется |
| Реальные запасы и нормы | Подтверждение отсутствует | Только явно учебный ресурсный сценарий |
| Метка ML | Стадия и единицы не подтверждены | Обучение заблокировано |
| Ошибки ML | Есть лишь индексная диагностика q2; одна утечка | Полезность ML не установлена |
| Охват | Черновик 662 строки, 6 марок; нет временных частей | Нельзя обещать все марки и новые рецептуры |
| Solver API | Независимый маленький MILP дал цель 3; публичная signature сохранена | Передача и потребление MIP-start не доказаны |
| Контроль модели | Перебор, MILP и валидатор совпали на трёх сценариях | Доступен проверяемый резервный путь |

Проверка API относится к установленной версии scipy; не переносится на все решатели. Источник: `../results/I3-A-09_api_audit.json`; документы I3-K-07/08 также фиксируют not_confirmed.

Один основной кандидат — ресурсный MILP с явно заданным q. Одна жадная эвристика может служить контролем будущего сравнения, без обещания тёплого старта или ML для неизвестных рецептур. Финальный майский тест не выполнен.
