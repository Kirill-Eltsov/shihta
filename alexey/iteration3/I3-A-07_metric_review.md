# I3-A-07. Аудит контрольных прогнозов

Независимо воспроизведена арифметика диагностики `scripts/i3_k06_baselines.py`, без обучения и без финального майского теста. Вход — 46 мартовских агрегированных значений нормированного q2; разбиение по индексу: 32/14. Это не событийное временное разбиение.

| Способ | MAE | Интерпретация |
|---|---|---|
| Постоянная 1 | 0.5038343255 | Диагностический контроль |
| Среднее обучения | 0.4545930630 | Лучший из этих двух контролей без использования test в среднем |
| Глобальное среднее всех 46 | 0.4121787538 | Использует test-ответы; исключить из честного сравнения |
| simple_mean_model | 0.4545930630 | В точности повторяет среднее обучения; не новая модель |

Все четыре значения совпали с сохранёнными результатами до допуска 1e-12. Выигрыш ML не доказан: допустимого обучающего эксперимента нет. Ошибки контроля по 14 ключам марка/рецепт и размеры групп сохранены в `../results/I3-A-07_metric_audit.json`. Размерные ошибки событий по этим нормированным агрегатам установить нельзя.

Требования к fallback: только средние обучения, иерархия рецепт → марка → глобальное; отдельные покрытие и ошибки fallback, особенно для невиденных рецептур. Использование y_test при расчёте fallback запрещено. Замечания к реализации: исключить утечку, индексную имитацию времени и обозначение среднего как отдельной модели. До подтверждения метки выводы ограничиваются диагностикой.
