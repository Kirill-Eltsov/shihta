# I3-A-01. Метка и признаки

Статус: определение метки подготовлено; применение к производственным данным заблокировано.

Кандидат метки y=good/(good+bad), только при положительном знаменателе, одинаковых единицах good и bad, взаимоисключающих исходах и определённой стадии. Повторные операции и возврат на доработку должны быть разрешены в правилах учёта. Это выход годного на стадии, а не автоматически вероятность соответствия конечной продукции. В исходной диагностике good/bad имеют единицы шт.; заголовок processed в т не подтверждает преобразование. Нормированный q2 не равен исходному выходу.

| Признак | Решение |
|---|---|
| Нормативный состав, марка, версия рецептуры | Допускать после подтверждения, что версия известна до выбора |
| Свойства доступного сырья, плановые настройки | Допускать только с подтверждённым временем доступности |
| ID рецепта | Можно для известных рецептур; не доказательство переноса на новые |
| Фактические good/bad, брак, обжиг и сортировка текущей партии | Исключить из входов, если получены после выбора |
| Фактический расход и окончательный состав | Исключить, если измерены после решения |
| event_id | Ключ контроля дублей, не содержательный предиктор |

Нужны подтверждение единиц, стадии, знаменателя, повторов и временная привязка каждого признака. Флаг feature_after_recipe_flag=False сам по себе этого не доказывает.
