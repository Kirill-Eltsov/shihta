# I3-A-02. Временное разбиение

Март — обучение; апрель — выбор модели, настроек и правил fallback; май — единственный финальный тест. Майские ответы не используются в выборе признаков, нормировок, модели или порогов.

Одна партия и её повторные измерения не попадают в разные части. Все агрегаты, средние и преобразования обучаются только на обучающей части. После выбора по апрелю разрешено переобучить выбранную процедуру на март+апрель, сохранив май нетронутым; этот режим фиксируется до открытия теста.

Для каждой части сохранить строки, партии, марки и ключи марка+версия рецептуры. Оценки для известных и невиденных в обучении рецептур разделить. Fallback: среднее рецепта → среднее марки → глобальное среднее, вычисленные только по данным обучения. Этот fallback не считается доказательством способности предсказывать новую рецептуру.

Предварительные метрики: MAE; взвешенная MAE по подтверждённому объёму; ошибки по маркам, рецептурам и масштабу событий; макросреднее по рецептурам. Для вероятностной метки дополнительно понадобится отдельная проверка калибровки.

Текущая таблица без точного времени и метки не позволяет построить подтверждённые временные части. Индекс строки не заменяет время.
