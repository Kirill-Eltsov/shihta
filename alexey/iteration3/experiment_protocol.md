# I3-A-08. Единый протокол сравнения

Сценарии: I3-A-06_scenarios.md. Версия протокола фиксируется до будущей серии. Текущие контрольные примеры уже изучены и не считаются независимым тестом эффективности.

Одинаковые входы и q для методов одного экземпляра. Сохранять SHA256, commit исходников, версии, параметры, окружение, число потоков и seeds. Общий лимит — 120 секунд на метод и экземпляр, включая подготовку и валидацию. Стохастические методы: seeds 0–9. Детерминированные: один основной запуск, затем три повтора для времени; результаты всех повторов сохраняются. Повторы не превращать в выбор самого выгодного результата.

Раздельные таймеры: загрузка/подготовка, прогноз или эвристика, построение модели, решение, валидация; полная стоимость — их сумма. Неподдерживаемую настройку потоков помечать явно. Учесть полное время подготовки начального решения, если такой интерфейс будет доказан.

Независимая проверка плана: ровно одно назначение каждому заказу, разрешённые кандидаты, полный баланс, конечные коэффициенты. Допуск ресурсов: 1e-8 + 1e-9*abs(stock), единицы т. Для совпадения контрольных целей abs_tol=1e-8, rel_tol=1e-9.

Статусы: optimal — доказанный оптимум; feasible — проверенный план без доказанного оптимума; infeasible — доказанная несовместность задачи; timeout_with_plan и timeout_without_plan — отдельно; no_solution_found — эвристика не нашла решения; invalid_plan и error — отдельно. Неудача эвристики не доказывает infeasible.

Публиковать покрытие, долю допустимых планов, цель только допустимых, время до первого допустимого, общее время, solver bound/gap при корректном статусе. Отрицательные результаты и все отказы сохранять. Разные q — разные задачи. Скорость на трёх малых контролях не является доказательством масштабируемости.
