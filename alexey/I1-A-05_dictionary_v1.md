## Словарь критичных полей

Источник: `data/raw/*.xls`, текущий `scripts/00_data_prep.py`, `docs/keys.md`, обработанные CSV. Исходные книги имеют месячные листы март/апрель/май 2022. Точный лист и строку для каждого события сохраняет загрузчик; утверждение единиц из заголовков требует технологической проверки.

| Поле | Источник | Единица / смысл | Статус и зависимость |
|---|---|---|---|
| period, order_id | zakazy.csv; Заказы.xls | месяц и локальный ID строки потребности | Технический ключ period+order_id, не глобальный номер клиента |
| mass_code | Заказы.xls, Шихта.xls | код марки массы | Связь есть технически; не доказывает взаимозаменяемость |
| Доп. марка | исходный Заказы.xls | дополнительный признак позиции | В zakazy.csv отсутствует; нужен для проверки строгих кандидатов |
| order_t, extra_order_t, demand_t | zakazy.csv | т; demand складывается из основного и дополнительного | Суммирование и масса изделия/смеси требуют ответа |
| shikhta_num | recepty.csv; Шихта.xls | номер рецептуры внутри марки/периода | Ключ включает period, mass_code |
| powder_code, norm_pct | recepty.csv; Шихта.xls | компонент; норма в процентах | База нормы и добавки сверх основы не подтверждены |
| substitutes | recepty.csv | справочные коды замен | Наличие строки не даёт автоматического разрешения замены |
| A_c / stocks | нет подтверждённого stocks.csv | т доступного сырья на дату | Промышленный баланс заблокирован |
| nMaterialId | Подача порошков.xls | код материала движения | Нужен справочник соответствий, это не остаток |
| good_t, scrap_t | kachestvo.csv | заголовки заявляют т | Перепроверить преобразование из исходных шт/т; не считать заголовок доказательством |
| press_yield, q2_press_yield | kachestvo.csv | доля и нормированная оценка | Не взаимозаменяемы; нормировка q2 не сохраняет смысл вероятности |
| event_id, known_at | ml_events_draft.csv | идентификатор и текстовая отметка доступности | Нет точной даты, good/bad и метки в черновике |
