# I2-A-02 — Критерий качества и методы исходной работы

Источники: `docs/MILP_Solvers.ipynb`, `scripts/i2_k06_milp.py`, документы I2-K-06/09. Notebook доступен и просмотрен; полный прогон его 40 экспериментов не воспроизводился в рамках этой задачи.

## Целевая функция

$$\max F(x)=\sum_{o\in O}\sum_{r\in R_o}d_o q_{or}x_{or}.$$

q_or — явно заданная оценка выбора рецептуры r для заказа o. Если она зависит только от марки и рецептуры, это частный случай. d_o — тоннаж, x_or — выбор 0/1. Для условного безразмерного балла q величина F имеет смысл балл·т. Она не является вероятностью соответствия и не означает автоматически выпуск годного в тоннах.

## Что делает исходная работа

| Вариант | Смысл | Ограничение интерпретации |
|---|---|---|
| q1 | Нормированный ранг номера шихты внутри марки | Условная оценка; номер рецептуры не доказывает качество |
| q2 | Оценка на основе доли годного при прессовке с нормированием внутри марки | Единицы исходных показателей и база доли требуют проверки; после нормирования не является исходной долей |
| q3 | Оценка соответствия фактических показателей нормам | Не является сама по себе вероятностью; нужны правила и единицы |
| q4 | Оценка по группе дефектов; при наличии групповой нормы одинакова для рецептур марки, иначе используется ранг | Постоянная внутри марки часть не различает её рецептуры |
| q5 | Смесь 0.4 q2 + 0.4 q3 + 0.2 q4 | Весовые коэффициенты — правило исходной реализации, внешнее обоснование не подтверждено |

Исходный notebook сравнивает MILP/HiGHS, LP с округлением, ILP/CBC, жадные методы, имитацию отжига, случайные перезапуски и декомпозицию с венгерским методом. Это набор методов сравнения, а не один утверждённый метод предприятия.

MILP соответствует линейной цели и ресурсным ограничениям с бинарными решениями. Выбираем его как точный контрольный метод для учебного случая; оптимальность признаём только по статусу решателя и независимой проверке. При остановке по времени лучший найденный план не обязательно оптимален. Эвристики требуют той же проверки допустимости.

## Что установлено при сверке кода

- `i2_k06_milp.py` использует 25 крупнейших мартовских позиций; q2, а при пропуске — 0.5. Эта подстановка является явным допущением скрипта и не принимается автоматически в наш контракт.
- В этом скрипте нет ресурсных ограничений. Документ I2-K-09 корректно называет комплект учебным.
- В исходном notebook `compute_metrics(asgn)` использует глобальный `quality`; в цикле сравнения методов передаётся q_dict, но оценка результата вызывается без q_dict. Поэтому цель нужно независимо пересчитывать с тем же q, с которым решалась задача.
- Выбор по максимальному q каждого заказа при отсутствии общих ресурсных ограничений не проверяет способность метода распределять дефицитное сырьё.

## Принято для учебной проверки

Явно заданные баллы q, единая цель для всех методов и проверка только полных допустимых планов. Произвольная замена пропусков на 0/0.5 исключена. Нормы состава автоматически не нормируются. Производственная интерпретация q, разрешённые рецептуры и реальные запасы остаются открытыми.
