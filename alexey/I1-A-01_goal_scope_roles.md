## 1. Цель

Исследовать выбор допустимых рецептур шихты для заказов при ограниченных запасах сырья и явно заданном показателе качества решения. Получить проверенную математическую модель и воспроизводимое сравнение выбранного метода с базовым методом сравнения.

Выбор рецептур определяет, по какой рецептуре выполнять каждый заказ. Проверка баланса отдельно устанавливает, хватает ли каждого компонента сырья при выбранных рецептурах, объёмах заказов и нормах расхода. Допустимый план должен пройти эту проверку.

## 2. Границы проекта

Предлагаемая постановка: один расчётный период, каждая позиция заказа целиком выполняется по одной разрешённой рецептуре. В работу входят описание входных данных и правил, выбор рецептур, независимая проверка плана, расчёт показателя решения и сравнение методов на одинаковых условиях.

Планирование печей и смен, закупки и разработка новых составов в текущий объём не входят. Учебные примеры с заданными запасами и оценками используются для проверки программы; их результаты не подтверждают производственный эффект.

Для применения к производственным данным требуется подтвердить разрешённые рецептуры, смысл тоннажа, нормы расхода, доступные запасы и показатель качества решения.
