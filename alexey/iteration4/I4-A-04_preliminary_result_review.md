# I4-A-04 — Независимая проверка предварительного результата

Источник — коммит Кирилла `87f30c99af043a25142c84372812eee23c40051f`, файлы `data/processed/i4/scenarios_v1.json` и `k_control_results.json` из той же папки. Входы побайтово совпали с `alexey/iteration4/scenarios_v1.json`, SHA-256 совпал с хешем в результате Кирилла.

Сохранённые планы проверены через `alexey/validate_plan.py`, цель независимо пересчитана через `alexey/score_plan.py` с оценками q из каждого сценария. Проверены назначение ровно одной разрешённой рецептуры каждому заказу, запасы и совпадение расходов. Полный перебор подтвердил оптимумы и отсутствие допустимого плана при дефиците.

| Сценарий | Метод | План | Пересчитанная цель | Результат |
|---|---|---|---:|---|
| base | milp | H / L / L | 2.50 | Допустим |
| base | greedy | L / L / H | 2.35 | Допустим |
| deficit | milp | — | — | infeasible |
| deficit | greedy | — | — | no_solution_found |
| changed_q | milp | L / L / H | 2.35 | Допустим |
| changed_q | greedy | H / L / L | 1.65 | Допустим |

У четырёх выданных планов расход A, B и C составил 1,00, 0,90 и 1,10 т соответственно. Все значения совпали с сохранёнными. При запрете H для заказа 1 исходный план H/L/L отклонён. При изменении q для пары (1, H) старый план пересчитан на 1,65.

В контрольных результатах расхождений не обнаружено. Записи без полного допустимого назначения исключены из сравнения качества. Проверка относится к сохранённым результатам на синтетических сценариях. Новый запуск реализации Кирилла и проверка всей серии benchmark относятся к дальнейшим этапам.
